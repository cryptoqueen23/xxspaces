# XXFem Premium Website Prototype

This is a static prototype for the XX♀ brand concept.

## Files
- index.html
- style.css
- script.js

## Preview
Open `index.html` in your browser.

## Notes
- Uses Google Fonts and several Unsplash image URLs, so internet access is needed for those images/fonts.
- The "women in the meadow" hero is simulated using layered portrait imagery and CSS motion so you can see the concept now.
- For production, replace these images with licensed custom photography or a custom hero video/animation.
- Motion automatically reduces for users who prefer reduced motion.
